Motivation: Locally Good Can Be Globally Harmful

A locally beneficial prefetcher can be globally harmful. It may hide latency for one core while polluting shared cache or consuming bandwidth for its peer.

Key Idea: 3-Step Selector Concept

BWC chooses an expert for the local stream, then checks peer risk before activation.

  1. Sense— Track local stream features.
  2. Select— Pick orig, FDP, or BOP.
  3. Coordinate— Check peer signals before activation.

Takeaways

  • Workload-aware: runtime signals select the expert for the current stream.
  • Pair-aware: peer signals guard shared LLC and memory bandwidth.
  • Practical insight: prefetcher selection should coordinate across cores.
